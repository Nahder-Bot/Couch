# Phase 15.3: DESIGN-01 — wordmark master + mark master + sharp pipeline

**Status:** SHIPPED 2026-05-06 (commit `bf3bd7b`)
**Mode:** retrospective documentation — phase ran as interactive ChatGPT generation + Photopea editing rather than formal /gsd-plan-phase chain because the work was iterative and visual.

<domain>
## Phase Boundary

Produce the **PNG masters** for the new leather-cushion brand identity (refreshed 2026-05-06; replaces the original "film-reel C in italic display serif" direction) and the **`sharp`-based downscale pipeline** that generates the full Apple + Google + favicon + maskable + Android adaptive + Android notification icon matrix from those masters.

**Pivoted from** original "canonical SVG logo + wordmark sources" scope — the leather-cushion identity is photorealistic 3D-render which can't be vectorized without losing the leather texture or stitching detail. PNG masters + sharp pipeline replaces SVG plan.

**In scope (delivered):**
- `brand/mark-master.png` (1024×1024 SQUARE, no baked rounded corners) — leather-cushion C with glowing TV nested in C's opening (canonical brand-storytelling icon: couch facing TV)
- `brand/logo-master.png` (3000×1500, 2:1 aspect) — leather-cushion "Couch" wordmark
- `brand/notification-mark.png` (1024×1024 transparent) — flat white silhouette of the C with leather-C proportions
- `brand/README.md` — folder explainer + file table + no-baked-corners warning + regeneration command
- `scripts/regenerate-icons.cjs` — sharp pipeline producing 36 downscaled outputs from 3 masters
- 36 generated PNGs at repo root (mark-{21 sizes}, mark-maskable-{2 sizes}, mark-adaptive-{fg,bg}-432, logo-h{100,200,300}, favicon-{16,32,48}, notification-icon-{24,32,48,72,96})

**Out of scope (deferred):**
- favicon.ico multi-resolution (.ico) — sharp can't write .ico natively; HTML can link multiple favicon-{N}.png via `<link rel="icon" sizes>` instead
- Source SVGs — abandoned 2026-05-06 due to photorealistic 3D-render incompatibility
- Hand-traced SVG approximations — would lose leather texture/stitching, defeats the brand purpose
- Light-mode variants — Couch is dark-mode-only per CLAUDE.md
- Apple Watch / iPad-optimized variants — defer to post-launch

</domain>

<decisions>
## Implementation Decisions (locked retrospectively)

### Brand identity direction
- **D-01:** Leather-cushion wordmark replaces the original "film-reel C + italic display serif" concept (BRAND.md §1 refreshed 2026-05-06).
- **D-02:** Mark composition = leather C + glowing TV nested in C's opening (Option A from 2026-05-06 chat — TV+C version becomes canonical, NOT a clean C-only version).
- **D-03:** All assets share the same warm-dark leather backdrop (`#14110f` to `#0e0a07`), warm-brown leather material, cream/white stitching at panel seams, soft top-down lighting.

### Master file specs
- **D-04:** `mark-master.png` MUST be 1024×1024 perfect SQUARE with content filling all four corners — NO baked-in rounded corners (iOS/Android apply their own corner masks; baked corners cause "double-rounded" pinched look).
- **D-05:** `logo-master.png` at 3000×1500 (2:1 aspect ratio); user-generated master measured at exactly 2.000 aspect ratio.
- **D-06:** `notification-mark.png` at 1024×1024 with transparent background; flat white #FFFFFF silhouette with **leather-C proportions** (not generic font-C); axis-aligned (no tilt); residual faint halo accepted because it disappears at notification render sizes (24-96px).

### Generation method
- **D-07:** Masters generated via ChatGPT image generation per `.planning/CHATGPT-LOGO-PROMPTS-2026-05-06.md` (4 prompts: reference + mark + wordmark + silhouette). User Photopea-cleaned the wordmark for C+o alignment + white-background removal pre-handoff.
- **D-08:** No SVG sources produced. Photorealistic 3D-render incompatible with vector format.
- **D-09:** `brand/` folder lives at repo root. Source files in `brand/`, generated outputs at repo root (root level matches existing `mark-*.png` reference paths in `app.html` manifest).

### Downscale pipeline
- **D-10:** `scripts/regenerate-icons.cjs` (Node + sharp) reads the 3 masters and writes 36 downscaled PNGs at repo root, idempotent.
- **D-11:** sharp `lanczos3` kernel for all downscaling — preserves sharpness better than default cubic.
- **D-12:** PNG `compressionLevel: 9` for smallest file size at no visual cost (lossless).
- **D-13:** Maskable variants get extra 10% padding (W3C 40% safe-zone — circular masks won't clip the C).
- **D-14:** Android adaptive-icon foreground gets 33% safe-zone padding (108dp safe zone within 432dp canvas).
- **D-15:** Android adaptive-icon background = solid `#14110f` PNG (matches BRAND.md `--bg`).
- **D-16:** No favicon.ico — modern browsers prefer `<link rel="icon" type="image/png" sizes>` multi-link.

### Deployment
- **D-17:** New PNGs at repo root replace OLD identity PNGs in deploy via `bash scripts/deploy.sh <tag>` mirror loop.
- **D-18:** Phase 31 / Plan 31-04 already extends `deploy.sh` to mirror `brand/` + `marketing/` — no further deploy.sh changes needed.
- **D-19:** sw.js CACHE bump on icon update — recommend `couch-v49-design-01-canonical-assets` when this rolls to production (next deploy event).
- **D-20:** Single-repo couch-only — no queuenight changes, no firestore.rules changes.

### Documentation linkage

<specifics>
## Specific Notes

- **The TV+C composition** is the strongest piece of brand work to date. App Store reviewers should immediately grok the "couch facing TV = movie night" storytelling without text.
- **Halo on the notification silhouette** is accepted intentionally — at 24-96px Android notification render sizes, the halo compresses to a 1-pixel anti-alias edge that the system handles gracefully.
- **No favicon.ico** is a deliberate departure from convention — modern browser support for multi-link `<link rel="icon" sizes>` is universal; .ico adds complexity without benefit.
- **Apple Sign-In gotcha for Phase 17** stays separate — this phase only ships brand assets, not auth changes.

</specifics>
