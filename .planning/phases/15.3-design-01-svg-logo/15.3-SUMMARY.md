## Deviation from plan

The original Phase 15.3 plan (per ROADMAP.md narrative) called for "canonical SVG sources" with the existing PNGs as visual reference. Pivoted 2026-05-06 because:
1. The brand identity refreshed to a photorealistic 3D-render style (leather cushions + stitching) that can't be vectorized without losing texture
2. PNG-master + sharp pipeline produces equivalent regeneration capability with less complexity
3. SVG would have required hand-tracing the leather appearance, losing the photographic richness that defines the new brand

This deviation was discussed and ratified with the user in chat (commits c8879c9 + 707d680). All downstream consumers (Phase 17, Phase 31) updated to consume PNG masters instead of SVG.
