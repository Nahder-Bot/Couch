**4. Sentry breadcrumb wiring (per D-27):**

Add an inline `<script>` block immediately AFTER the closing `</main>` tag (before `</body>`). This script is small and standalone — does not need to live in /js/. Sentry is already loaded on landing.html at line 115 via the CDN script tag.

```html
  <script>
  // Phase 31 / D-27 — Sentry breadcrumb on FAQ open. Signals which questions
  // matter most so Phase 17 App Store description can order them by interest.
  // Defensive guard pattern (canonical across codebase — typeof !== 'undefined'
  // because Sentry CDN may fail to load in restricted environments / extensions).
  (function() {
    var faqItems = document.querySelectorAll('.faq-item');
    for (var i = 0; i < faqItems.length; i++) {
      faqItems[i].addEventListener('toggle', function(e) {
        if (!e.target.open) return; // only fire on open, not on close
        if (typeof Sentry !== 'undefined' && Sentry.addBreadcrumb) {
          var idx = parseInt(e.target.getAttribute('data-faq-index'), 10);
          Sentry.addBreadcrumb({
            category: 'marketing.faq',
            message: 'opened',
            data: { question_index: isNaN(idx) ? -1 : idx }
          });
        }
      });
    }
  })();
  </script>
```
