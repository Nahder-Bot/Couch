Surface it in the signin section of `app.html` above the Google Sign-In button per Apple HIG.

Purpose: Closes one App Review blocker (§4.8 compliance). No Firestore schema changes, no Cloud Function changes, no service-worker bump (auth flow is client-only). Bundles with Phase 17 Wave 1 work.

Output: Apple Sign-In button visible in production, click → Firebase Auth Apple provider → user authenticated.
</objective>

<title>Configure Apple Sign-In in Firebase Console + Apple Developer Console</title>
<action>
This task requires user action in two web consoles — Claude documents the steps and verifies via Firebase Auth REST API after user confirms completion.

User steps (~15-20 min):

1. Apple Developer Console (developer.apple.com):
   - Identifiers → "+" → "Services IDs" → Continue.
   - Description: "Couch Tonight Sign In Service"
   - Identifier: `app.couchtonight.couch.signin` (reverse-DNS sibling of Bundle ID; MUST be different from app Bundle ID)
   - Check "Sign In with Apple" capability → Configure:
     - Primary App ID: select `app.couchtonight.couch`
     - Domains and Subdomains: `couchtonight.app`
     - Return URLs: `https://couchtonight.app/__/auth/handler` (Firebase Auth handler — confirmed live in D-37 hotfix)
   - Save.

2. Apple Developer Console → Keys → "+" → "Sign in with Apple" → Configure → Primary App ID: `app.couchtonight.couch` → Save → DOWNLOAD the .p8 file (one-time download; loss = regenerate key). Note Key ID (10-char string).

3. Firebase Console (console.firebase.google.com → queuenight-84044 → Authentication → Sign-in method):
   - Apple → Enable
   - Services ID: `app.couchtonight.couch.signin`
   - OAuth code flow configuration:
     - Apple Team ID: `49R296FJGF` (confirmed in .continue-here.md)
     - Key ID: (from step 2)
     - Private key: paste contents of .p8 file from step 2
   - Save.

4. Backup the .p8 file to 1Password under "Couch — Apple Sign In Key (.p8)" with Key ID in the title. The .p8 is single-issue from Apple; if lost, regenerate (existing tokens stay valid until expiry).
