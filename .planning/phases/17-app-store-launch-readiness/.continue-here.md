## Critical Anti-Patterns (do NOT repeat these)

- **PWABuilder data:-URL manifest**: PWABuilder's scraper times out on data: URL manifests. Always externalize to `/manifest.json` real file. Already fixed; don't reintroduce inline manifests.
- **CSP `manifest-src 'self'` with data: URLs**: incompatible. Already fixed via real `/manifest.json`.
- **`scripts/deploy.sh` mirror loop**: previously had explicit allowlist that missed root-level icon PNGs (Phase 15.3 maskable + adaptive variants 404'd in production for ~6 days). Now uses `cp -v *.png` glob. If you add new file types at root, extend the mirror loop.
- **`form_input` on App Store Connect dropdowns**: Apple's React UI doesn't pick up programmatic select changes. Use a JS HTMLSelectElement.value setter + dispatch `change` event, OR click the dropdown and pick visually.
- **Apple Developer iOS app for enrollment**: account-blocked for nahder@yahoo.com. Web enrollment was the path that worked.
